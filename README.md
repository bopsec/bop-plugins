# Instance coords overlay
Just for testing where the new instances were placed after the sailing update. Not on the plugin hub.

To mark tiles within the current instance slot, enter markers in **Additional tile markers** as
`X,Y,#RRGGBB` entries separated by semicolons. For example,
`12,34,#FF0000; 20,21,#00FF00` marks two tiles with red and green outlines.
Add as many entries as needed. Each marker uses the slot coordinates shown by
**Pos in slot**. Invalid entries and coordinates outside the slot are ignored.
The existing **Mark single tile** option still draws its tile in cyan.
